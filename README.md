## Overview
This project demonstrates an AI-powered load balancing system that dynamically routes traffic to backend servers using machine learning predictions.

## Features
- **Three Load Balancing Algorithms**: Round Robin, Least Connections, AI-Powered
- **Real-time Monitoring Dashboard** with WebSocket updates
- **Interactive Request Simulator** for testing
- **Performance Analytics** with charts and comparisons
- **Mock Backend Servers** (4 servers on ports 3001-3004)

## Technologies Used
- **Backend**: Node.js with Express.js
- **AI Service**: Python with Flask & Scikit-learn
- **Frontend**: HTML5, CSS3, JavaScript, Chart.js
- **Real-time**: Socket.IO
- **API Communication**: REST APIs
