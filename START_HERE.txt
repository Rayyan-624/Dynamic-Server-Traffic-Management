🚀 HOW TO RUN (CHOOSE ONE METHOD)
═════════════════════════════════════════════════════════════════════════════════

METHOD 1: AUTOMATIC (WINDOWS) - EASIEST
──────────────────────────────────────────
  1. Double-click: start.bat
  2. Wait for services to start (takes 3-5 seconds)
  3. Open browser: http://localhost:3000
  Done! ✅


METHOD 2: AUTOMATIC (MAC/LINUX) - EASIEST
──────────────────────────────────────────
  1. Open terminal in project directory
  2. Run: chmod +x start.sh && ./start.sh
  3. Wait for services to start
  4. Open browser: http://localhost:3000
  Done! ✅


METHOD 3: MANUAL - ALL PLATFORMS
──────────────────────────────────────────
  SETUP (ONE TIME):
    npm install
    cd service
    pip install -r requirements.txt
    cd ..

  RUN (3 TERMINAL WINDOWS):
    Terminal 1: npm start
    Terminal 2: cd service && python app.py
    Terminal 3: npm run traffic    (optional - for testing)

  THEN: Open http://localhost:3000

🚨 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

"Port 3000/5000 already in use?"
  → Use different port or kill existing process
  → See QUICKSTART.txt for port killing commands

"npm/python not found?"
  → Check installation and PATH environment variable
  → Restart terminal after installation

"Dashboard not loading?"
  → Clear browser cache (Ctrl+Shift+Del)
  → Hard refresh (Ctrl+F5)
  → Try incognito window

"AI service not connecting?"
  → Check if Flask running on port 5000
  → Verify no firewall blocking
  → Try running manually: cd service && python app.py

For more help, see INSTALLATION.md and README.md
